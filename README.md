# 元素大對決

元素卡牌比大小遊戲。22 張元素卡平分給兩邊，每回合兩張卡都翻開，卡上**只有原子序和週期表上的位置**，輪到的人要靠週期趨勢，選一個自己一定會贏的項目，贏走對手的卡！每回合比完都會說明為什麼，玩著玩著就記住週期表的趨勢。

適合國中理化、高中化學，可以當課堂分組競賽、下課小遊戲或複習活動。

**整個遊戲只有一個 `index.html` 檔案，不用網路、不用安裝、不用註冊，也不會蒐集任何個人資料。**

## 玩法

1. 選擇對手：**挑戰電腦**，或**兩人對戰**（兩隊用同一台電腦輪流）
2. 選擇回合數：10 回合、20 回合，或收完所有卡
3. 每回合兩邊各出最上面的一張卡，**兩張卡都翻開**
4. 輪到的人看兩個元素在週期表的位置，選一個**自己一定會贏**的項目：原子量、原子半徑、電負度、游離能
5. **選對了**（自己的比較大）就贏走兩張卡；**選錯了**，兩張卡都給對方
6. 兩邊**輪流**選，比的是誰對週期趨勢判斷得比較準
7. **判斷不出來就算平手**：如果兩張卡一個在左上、一個在右下，兩個趨勢方向相反，只看位置判斷不出來，這回合算平手，兩張卡放中間，下一回合的贏家一起拿走
8. 回合結束時卡比較多的人獲勝；或一方的卡被收光就結束

例如：鈉對氯，鈉在左邊，選「原子半徑」就會贏；選「電負度」就會輸。

## 卡牌內容

22 種主族元素與稀有氣體：H、He、Li、Be、B、C、N、O、F、Ne、Na、Mg、Al、Si、P、S、Cl、Ar、K、Ca、Br、I

每張卡只有：中英文名稱、分類（鹼金屬、鹵素、稀有氣體……）、**原子序**、**迷你週期表上的位置**（第幾週期、第幾族）。卡上不寫數值，玩家要用週期趨勢來判斷。

## 每回合的說明

比完會用文字說明誰比較大、為什麼，不列數值：
- 照趨勢的情況：例如「鋰在鈹的左方，照趨勢，鋰的原子半徑比較大」
- 例外的情況：例如氮的游離能比氧大（半滿的軌域比較穩定）、氬的原子量比鉀大（中子比較多）、稀有氣體的原子半徑
- 判斷不出來的情況（一個在左上、一個在右下）：算平手，並說明兩個趨勢方向相反，順便告訴玩家實際上誰比較大

所以除了少數課本上的經典例外，**每一回合的輸贏都能靠週期表的位置推理出來**。

## 判斷勝負用的資料

卡上不顯示，但遊戲內部用以下標準資料判斷誰比較大：
- 原子量：IUPAC 標準原子量
- 原子半徑：單鍵共價半徑
- 電負度：鮑林電負度（稀有氣體沒有電負度，比電負度時一定輸）
- 游離能：第一游離能

若發現判斷有誤，歡迎提出 Issue。

## 教學建議

- **課堂競賽**：分兩隊上台對戰，每次比完請台下同學說出趨勢
- **說出理由**：選項目之前先請學生說出「為什麼覺得會贏」
- **找例外**：請學生記錄遊戲中出現的「例外」，再討論原因
- **說出理由**：選項目時要大聲說出「因為它在比較左下方……」
